# Contributing

- The docs are the source of truth — keep them concise, practical, and self-contained
- Keep commands copy-pasteable and sequential
- Use placeholders for personal/project-specific values (e.g. `<name>`, `<email>`)
- Don't hardcode versions where a "latest" or "LTS" option exists, unless pinning is intentional
- If you notice something that could improve the docs (new tool, better approach, missing step, gotcha, etc.), mention it — suggestions are welcome
